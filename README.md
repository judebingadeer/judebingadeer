- **ATHAR — AI-Powered Heritage Guide**  
  An interactive guide for exploring Saudi heritage landmarks through recognition and bilingual Arabic–English assistance. Developed as a team project during the Tuwaiq Academy × Google Cloud Computing Program.

- **University Course Evaluation System**
